Capabilities

Everything in one place

40+ operations across every major SentinelOne resource — run from a CLI or a browser form in seconds.

🏢
Account Management
List, get, create, and configure accounts. Manage policies, update settings, and switch tenants.
list-accounts get-account account-policy create-account
🌐
Site Management
Browse and manage all sites across your accounts. List, create, update, and delete sites.
list-sites create-site update-site delete-site
🤖
Agent Operations
Query agents, trigger scans, initiate decommission, move agents between sites, and manage endpoints.
list-agents initiate-scan decommission move-agents
🔴
Threat Response
List and investigate active threats, mark as resolved, and take mitigation actions.
list-threats resolve-threat threat-summary
📊
Usage Metering
Pull billing-period endpoint counts, usage reports per account or site, and compare periods via PowerQuery.
usage-report endpoint-count metering-summary
🔧
Groups & Exclusions
Manage agent groups and path/process exclusions at the account or site level.
list-groups list-exclusions
⚙️
Config & XDR
Manage configuration overrides and query the XDR / Data Lake for deep endpoint telemetry.
config-override xdr-query data-lake
🚀
Multi-profile Support
Switch between tenants instantly with named profiles. Credentials are stored securely, never in plain config files.
--profile multiple tenants session-based
📤
Flexible Output
Get results as a formatted table, raw JSON, or CSV. Use --columns to select fields, pipe into jq or spreadsheets.
table json csv --columns
Installation

Get started in minutes

Runs on Python 3.9+. No external services required.

1

Clone & install

git clone https://github.com/pavanmudalagi/S1adminportal
cd S1adminportal
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
2

Set credentials

Export your SentinelOne credentials (or let the CLI prompt you):

export S1_BASE_URL="https://your-tenant.sentinelone.net"
export S1_API_TOKEN="your-api-token"
export S1_AUTH_PREFIX="APIToken"
3

Run the CLI

python -m s1am list-accounts
python -m s1am list-agents --all
python -m s1am --profile acme list-sites
4

Or launch the Web UI

./scripts/start.sh
# opens http://127.0.0.1:5173

Configuration
Credentials are resolved in priority order:
1. Environment variables
2. ~/.config/s1am/config profile file
3. Interactive prompt at runtime (hidden input)
Named Profiles
python -m s1am --profile acme list-accounts
python -m s1am --profile prod list-agents

How to run the Web UI

1

Start the server

./scripts/start.sh
# or: python run_web.py
# or: ./scripts/start.sh --port 8080
2

Enter credentials in the UI

The first time you open the portal, you'll be prompted for your SentinelOne base URL and API token. Credentials are stored in a signed session cookie — never written to disk.

3

Switch profiles

Use the profile selector in the top bar to switch tenants. Display names are persisted in ~/.config/s1am/web_labels.json.

Web UI Features

  • ✓ 40+ operations across Accounts, Sites, Agents, Threats, Metering, Config, XDR
  • ✓ Table, JSON, and CSV output — copy results to clipboard in one click
  • ✓ Real-time streaming output — long-running paginated queries show progress live
  • ✓ Multi-profile — manage multiple SentinelOne tenants from the same portal
  • ✓ All operations run as CLI subprocesses — full audit trail in your terminal
