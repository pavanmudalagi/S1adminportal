What you need to know

  • Prompt Security uses a separate console with its own roles and permissions.
  • As a super admin, you can add additional users.
  • You can use role-based access control (RBAC) to give other users permission to manage users, so the super admin does not need to handle every request.
  • Prompt activity may include user interaction content. Access should be limited to appropriate authorised users. Prompt text can be hidden by default, with audited access when it needs to be viewed.
  • As this is an early-access offering, provisioning and support processes are still being refined, and some steps may be handled manually.
